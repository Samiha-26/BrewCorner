# BrewCorner

BrewCorner is a responsive, modern landing page for a coffee shop. It features a clean design, showcasing the shop's story, popular menu items, unique selling points, and opening hours.

## Features

- **Responsive Design**: Built to look great on desktop, tablet, and mobile devices.
- **Hero Section**: An inviting introduction with a strong call to action.
- **Our Story**: A section dedicated to the history and passion behind the coffee.
- **Menu Highlights**: Displays popular picks with images, descriptions, and prices.
- **Why Us**: Highlights key features like fresh beans, fast delivery, and care.
- **Opening Hours**: Clear, easy-to-read schedule.
- **Footer**: Includes quick links, contact information, and social media icons.

## Technologies Used

- **HTML5**: For semantic structuring of the content.
- **CSS3**: For styling, layout, and responsive design.
- **Google Fonts**: Uses Arimo, Inter, Merriweather, and Open Sans.
- **Font Awesome**: Used for social media and copyright icons.

## Getting Started

To view the project locally, simply clone the repository and open the `index.html` file in your preferred web browser.

```bash
# Clone the repository (if applicable)
git clone <your-repository-url>

# Navigate to the project directory
cd BrewCorner
```

Open `index.html` in your browser to view the site.

## File Structure

- `index.html`: The main HTML document containing the structure of the landing page.
- `style.css`: The stylesheet containing all the CSS rules for the layout and design.
- `image/`: Directory containing all the images used on the website.
